# 随手摘录

这里保存有启发、值得以后再看，但暂时不足以写成正式知识笔记的**博主观点、短文片段、日常感悟与实践观察**。

它是轻量收藏区，不等同于已经核验或吸收的正式知识库。

## 记录方式

- **按年汇集**：先按年份保存，一个观点一个小节；不默认一条摘录建立一个文件。
- **短而忠实**：保留核心观点、关键例子和一条可能有用的启发，不机械扩写成长文，也不把作者经验写成普遍事实。
- **来源可追溯**：有作者、原链接、发布时间就记录；没有则写“待补”，绝不猜测。
- **版权清晰**：NoIT 是公开仓库。未经授权的第三方作品只做忠实转述与必要的少量短引，不公开搬运全文；全文需要保留时用私有或本地档案。
- **按价值升级**：同类观点经过实践或跨来源验证，形成可长期复用的方法后，再融合进入相关正式知识文档；不在两处重复堆砌。
