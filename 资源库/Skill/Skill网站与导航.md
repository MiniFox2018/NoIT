# Skill 网站与导航

> 本页保存用于发现、筛选和查找 Skill 的入口。收录某个导航站不等于认可其中全部项目，也不自动把站内 Skill 全量导入 NoIT；具体技能仍按本目录规则逐项核对。

用于发现、筛选和查找 Skill 的网站入口。具体技能及安装状态见 [[Skill收藏与安装清单]]。

| 网站 | 用途与特点 |
|---|---|
| [LearnPrompt Skill 工坊](https://www.learnprompt.pro/skills) | LearnPrompt 项目的展示与发现入口，按“迭代中”和“稳定可用”组织项目，提供用途简介及部分安装命令；适合查找演示制作、内容处理、阅读与 Agent 工作流相关工具。页面也包含普通工具和指南，具体项目仍需核对是否是 Skill。 |
| [UI Skills](https://www.ui-skills.com/) | 面向设计工程的精选技能目录，覆盖前端设计、界面审查、动效、无障碍与交互细节；页面提供作者与技能简介，并有 CLI 和 MCP 入口，适合按具体界面任务寻找技能。 |
| [Hermes Atlas · Top Skills](https://hermesatlas.com/lists/top-skills) | 面向 Hermes Agent 的技能推荐项目列表，提供项目详情入口与用途概述，覆盖开发流程、安全、设计和内容等领域；适合发现候选项目，不能仅凭入选就认定适配 Codex 或通过质量验证。 |
| [SkillsMP](https://skillsmp.com/) | 索引公开 GitHub Skill 的社区平台，可按关键词和职业领域查找示例；适合比较类似技能的范围、步骤、检查清单和支持文件。网站明确说明其不负责安装或质量认证，使用前仍需查看原仓库。 |
| [Awesome Claude Video Skills](https://github.com/zhuyansen/awesome-claude-video-skills) | 视频 Skill 与工具包的分类导航，覆盖视频框架、宣传演示、知识讲解、剪辑、短视频、虚拟人物与动效等，并提供示例预览和可筛选的在线列表。仓库本身没有 Skill 文件；作者给出的安全分级仅作为筛选线索，不等于本次已验证各项目安全。 |
| [Claude Marketplaces](https://claudemarketplaces.com/) | 面向 Claude Code 的扩展目录，分别浏览 Skill、MCP Server、插件与插件市场，提供详情页、安装入口和热门项目展示；适合发现技能及配套工具。排序参考安装量、星标和使用等信号，不能据此认定质量、安全性或 Codex 兼容性；插件、市场和 MCP 不等于单个 Skill。 |
| [CocoLoop AI 社区](https://www.cocoloop.cn/) · [Skill 技能专区](https://www.cocoloop.cn/c/skill/6) | 中文 AI Agent 社区，设有独立的 Skill 分享与讨论区，包含技能发布、玩法、教程和问题交流，并有 OpenClaw 等产品的安装与使用讨论；适合发现社区技能与实践资料。社区文章需逐篇核对来源和适用环境，本次只收录入口，不展开安装或收藏全部帖子。 |
