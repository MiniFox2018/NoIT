# Depth of Field Simulator：景深与视场模拟器

## 它是什么

Depth of Field Simulator 是 Jack Herrington 制作的浏览器端交互工具，用来可视化：

- 焦距；
- 光圈；
- 主体距离；
- 传感器尺寸；
- 弥散圈；

如何共同影响：

- 近景深；
- 远景深；
- 总景深；
- 超焦距；
- 视场角；
- 35mm 等效焦距。

它的价值不只是“帮你算一个数字”，而是可以拖动参数，直接建立**镜头参数变化 → 画面空间变化**的直觉。

## 适合什么时候用

### 学习景深

逐项只改一个变量：

1. 固定焦距和距离，只改光圈；
2. 固定光圈和距离，只改焦距；
3. 固定焦距和光圈，只改主体距离；
4. 再切换不同传感器。

这种方式比背“口诀”更容易建立因果直觉。

### 拍摄前估算

可以快速判断：

- 主体前后大致有多少容错；
- 某个焦距 / 光圈组合是否容易让多个人同时清晰；
- 风光中大致需要在哪里对焦；
- 一个镜头属于浅、中还是深景深。

### AI 影像创作

在写 AI 图像 / 视频 Prompt 前，可以先用模拟器理解：

- 24mm / 35mm / 50mm / 85mm 的视场差异；
- 大光圈与近距离为何容易产生浅景深；
- 同样构图下不同画幅与焦距为什么会改变空间感觉。

再把结果转成模型能理解的画面描述，而不是机械塞进参数。

## 使用方法

最适合的使用方式不是一次把参数调到“最好”，而是做控制变量实验。

### 练习 1：光圈

固定：

- Full Frame；
- 50mm；
- 主体距离 2m。

依次比较：

~~~text
f/1.4
f/2.8
f/5.6
f/11
f/16
~~~

观察近端、远端、总景深和衍射提示。

### 练习 2：距离

固定：

- 50mm；
- f/2.8。

逐渐把主体从近处移远。

观察景深如何扩展，以及远端何时快速变大。

### 练习 3：焦距

固定相机位置和主体距离，对比：

~~~text
24mm → 35mm → 50mm → 85mm → 135mm
~~~

然后再做一次“维持主体大小基本不变”的实验。

这能帮助理解：

> 固定距离比较焦距，与固定构图比较焦距，是两个不同问题。

### 练习 4：画幅

对比 APS-C、全画幅和 MFT。

先看相同实际焦距，再用“等效视角”重新比较，避免得出过度简化的画幅结论。

## 重要限制

### 1. CoC 是假设，不是真理

工具预设的弥散圈用于方便计算。

如果最终用途是：

- 大幅打印；
- 高分辨率商业摄影；
- 大比例裁切；

应采用更严格的标准。

### 2. 当前“∞”显示有场景上限

截至核验 commit，代码把 360 英寸（约 9.14m / 30ft）作为可视场景远端。

当计算的远景深超过这个范围时，UI 会把远端显示为“∞”。

因此：

> 对长距离场景，当前“∞”不能直接当成严格的数学结论。

需要精确远景深时，应使用公式或其他专业计算工具复核。

### 3. 衍射提示是近似

当前代码用 Airy disk 与 CoC 的近似关系给出风险提示。

真实衍射影响还受：

- 波长；
- 像素密度；
- 镜头像差；
- 后期锐化；
- 最终输出；

影响。

### 4. 工具不替代现场测试

景深计算不能预测所有真实镜头表现，例如：

- 焦外形态；
- 像场弯曲；
- 球差；
- 对焦漂移；
- 镜头实际 T-stop；
- 边缘像质。

重要拍摄仍应做实拍验证。

### 5. 源代码许可需要单独确认

截至 2026-10-03，仓库根目录未发现明确的 LICENSE 文件。

因此可以把在线工具作为外部资源使用和学习，但如果要复制、改造或重新发布其源代码，应先向作者或仓库确认许可，不要因为代码公开就默认可以任意再分发。
