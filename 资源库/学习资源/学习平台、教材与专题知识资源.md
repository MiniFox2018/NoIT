## Think DSP

- 主入口：https://allendowney.github.io/ThinkDSP/
- 第二版草稿：https://allendowney.github.io/ThinkDSP2/

### 它是什么

Allen B. Downey 编写的数字信号处理入门教材，采用 Python、Jupyter Notebook 和可运行示例，从“先动手观察信号”切入 DSP，而不是先从大量抽象数学推导开始。

教材同时提供：

- 数字信号与波形；
- 频谱与谐波；
- 滤波；
- 卷积；
- 傅里叶相关内容；
- 随机信号；
- Jupyter 示例和练习。

### 为什么值得留

它属于**可以真正拿来系统学习的教材型资源**，不是普通教程导航。

官方当前说明中，第一版仓库保留已出版版本及配套 Notebook，而较新的 ThinkDSP2 是第二版草稿；如果从零开始学习，优先看第二版更合理。

### 使用方式

~~~text
先跑 Notebook
→ 看图和实验结果
→ 再理解数学关系
→ 修改参数观察变化
→ 回到推导解释现象
~~~

适合已经会基础 Python、希望用计算实验理解信号处理的人。

### 许可与边界

第一版明确采用 CC BY-NC-SA 4.0。可以在遵守署名、非商业和相同方式共享要求的前提下使用。

NoIT 当前只登记学习入口，不复制整本教材。若以后决定系统吸收，应基于许可要求保留来源和授权信息，并优先处理最新第二版内容。

## 古文岛（原古诗文网）

- 入口：https://www.gushiwen.cn/

### 它是什么

中文古典文学查询与学习平台，当前页面品牌显示为“古文岛（原古诗文网）”。

主要覆盖：

- 古诗词；
- 文言文；
- 名句；
- 古籍；
- 作者；
- 字词；
- 译文、注释、赏析、拼音等辅助信息；
- 按朝代、主题、教材阶段等方式浏览。

### 什么时候值得打开

- 查一首诗、词或文言文的原文；
- 查作者、生平和相关作品；
- 找某个主题的古诗文；
- 学习小学、初中、高中常见古诗文；
- 快速核对字词、译注和背景资料。

### 使用边界

把它当作**古典文学参考入口**，而不是自动视为权威校勘本。

原文版本、断句、异文、作者归属和历史解释如果用于严肃研究，仍应回到权威古籍整理本、出版社版本或学术资料核验。

网站自有的译文、赏析和整理内容不应整批复制进 NoIT。

## 地震“学”

- 入口：https://seismo-learn.org/

### 它是什么

面向中文地震学科研学习者的开放学习社区与文档体系，核心目标是提供地震学科研入门材料、维护学习资料并促进中文社区交流。

当前主要入口包括：

- 地震学科研入门教程；
- 地震学软件使用资料；
- 可持续维护的地震学参考书；
- 科研常用书签与链接；
- 开源文档与贡献入口。

### 为什么值得留

它不是单篇课程，而是一个完整的**专题学习入口**。

如果以后真正开始学习地震学，可以以它为入口，再把需要长期掌握的内容按主题吸收到系统知识库，而不是长期依赖网页导航。

### 当前处理

NoIT 先保留资源入口，不在当前任务中拆解整套地震学知识。

如果后续用户明确要求完整学习地震学，再逐个处理科研入门、软件、参考书和知识章节，避免一次性把整个站点机械搬进仓库。

## My IELTS

- 在线站点：https://hefengxian.github.io/my-ielts/
- GitHub：https://github.com/hefengxian/my-ielts

### 它是什么

一个中文雅思备考资源与练习项目，当前内容覆盖：

- 雅思核心词汇；
- 词汇打字练习；
- 语法资料；
- 听力考点与练习；
- 阅读同义替换；
- 写作训练；
- 部分音频、讲义和思维导图。

当前口语栏目仍未完整建设，因此不能把它视为覆盖全部 IELTS 模块的完整课程体系。

### 最适合怎么用

更适合当作：

- 雅思词汇练习站；
- 考点速查；
- 备考材料导航；
- 局部专项训练入口。

不要把它作为 IELTS 官方考试规则、评分标准或最新题型变化的唯一来源；这些内容应回查 IELTS、British Council、IDP、Cambridge 等官方或权威来源。

### 许可与版权边界

项目仓库当前未声明标准开源许可证，README 还明确写有“禁止将本项目用于任何商业目的”。

其中还整理了第三方出版物或课程相关内容，因此 NoIT **只登记项目入口和用途**：

- 不把第三方教材全文迁入仓库；
- 不复制音频、讲义或图书内容；
- 不将公开 GitHub 仓库误认为其中所有学习材料都具备开放再分发许可。

## ChinaTextbook

- GitHub：https://github.com/TapXWorld/ChinaTextbook

### 它是什么

一个体量很大的中国教材文件仓库，收录范围包括小学、初中、高中以及部分大学教材和数学学习资料。

项目定位更接近**教材文件集合与索引**，不是重新编写的课程。

### 为什么有价值

- 可以快速找到不同学段、学科和版本的教材线索；
- 对海外中文学习、教材比较、课程结构研究有参考价值；
- 大学部分也包含高等数学、线性代数、离散数学、概率论等资料入口。

### 重要边界

该仓库当前没有声明标准开源许可证，而且收录的教材本身涉及不同出版社和权利主体。

因此 NoIT 对它采取**只登记、不搬运**原则：

- 不把仓库中的 PDF 批量复制到 NoIT；
- 不因为文件出现在公开 GitHub 就推定其版权允许再次分发；
- 真正需要教材时，优先核对出版社、教育主管部门或官方数字教材平台；
- 若只用于查目录、版本和知识结构，可以把它作为检索线索。

这类资源的长期价值在于“找到资料”，不在于把整套教材镜像进个人知识库。

## 思辨录

- 入口：https://mind-guards.com/

### 它是什么

面向中文读者的批判性思维知识站，主要整理：

- 认知偏见；
- 逻辑谬误；
- 批判性思考方法；
- 互动自测；
- 概念之间的关联。

其词条组织强调定义、概念边界、推理结构、真实案例和应对方法，适合在遇到具体思维问题时按词条查阅。

### 与现有 NoIT 的关系

它与：

- [[思维阶梯：从证据更新到身份防御]]
- [[产品早期验证：先验证价值，再打磨细节]]
- [[AI辅助的系统化学习与输出工作流]]

具有明显互补关系。

前者强调“自己如何更新观点”，思辨录更像一套“识别具体偏见与论证错误的词典和训练入口”。

### 为什么本次不做全文知识吸收

思辨录的使用协议允许个人学习、研究以及在注明来源时适量引用，但明确限制大规模复制、自动化抓取，以及未经授权的复制、修改、分发和演绎。

因此本次采取：

~~~text
保留资源入口
+
记录其知识地图与适用场景
+
不复制词条正文
+
不做整站镜像式“完整吸收”
~~~

如果未来需要完善 NoIT 的批判性思维知识，应围绕“确认偏误、幸存者偏差、沉没成本、稻草人、假两难、循环论证”等主题，从可授权、可引用的多来源资料重新综合，而不是改写或搬运该站条目。
