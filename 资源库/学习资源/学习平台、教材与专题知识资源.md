## Think DSP

- 主入口：https://allendowney.github.io/ThinkDSP/
- 第二版草稿：https://allendowney.github.io/ThinkDSP2/

### 它是什么

Allen B. Downey 编写的数字信号处理入门教材，采用 Python、Jupyter Notebook 和可运行示例，从“先动手观察信号”切入 DSP，而不是先从大量抽象数学推导开始。

教材同时提供：

- 数字信号与波形；
- 频谱与谐波；
- 滤波；
- 卷积；
- 傅里叶相关内容；
- 随机信号；
- Jupyter 示例和练习。

### 为什么值得留

它属于**可以真正拿来系统学习的教材型资源**，不是普通教程导航。

官方当前说明中，第一版仓库保留已出版版本及配套 Notebook，而较新的 ThinkDSP2 是第二版草稿；如果从零开始学习，优先看第二版更合理。

### 使用方式

~~~text
先跑 Notebook
→ 看图和实验结果
→ 再理解数学关系
→ 修改参数观察变化
→ 回到推导解释现象
~~~

适合已经会基础 Python、希望用计算实验理解信号处理的人。

### 许可与边界

第一版明确采用 CC BY-NC-SA 4.0。可以在遵守署名、非商业和相同方式共享要求的前提下使用。

NoIT 当前只登记学习入口，不复制整本教材。若以后决定系统吸收，应基于许可要求保留来源和授权信息，并优先处理最新第二版内容。

- 入口：https://www.gushiwen.cn/

主要覆盖：

- 古籍；

- 按朝代、主题、教材阶段等方式浏览。

### 什么时候值得打开

- 查一首诗、词或文言文的原文；
- 查作者、生平和相关作品；
- 找某个主题的古诗文；

### 使用边界

原文版本、断句、异文、作者归属和历史解释如果用于严肃研究，仍应回到权威古籍整理本、出版社版本或学术资料核验。

## ChinaTextbook

- GitHub：https://github.com/TapXWorld/ChinaTextbook

### 它是什么

一个体量很大的中国教材文件仓库，收录范围包括小学、初中、高中以及部分大学教材和数学学习资料。

项目定位更接近**教材文件集合与索引**，不是重新编写的课程。

### 为什么有价值

- 可以快速找到不同学段、学科和版本的教材线索；
- 对海外中文学习、教材比较、课程结构研究有参考价值；
- 大学部分也包含高等数学、线性代数、离散数学、概率论等资料入口。

### 重要边界

该仓库当前没有声明标准开源许可证，而且收录的教材本身涉及不同出版社和权利主体。

因此 NoIT 对它采取**只登记、不搬运**原则：

- 不把仓库中的 PDF 批量复制到 NoIT；
- 不因为文件出现在公开 GitHub 就推定其版权允许再次分发；
- 真正需要教材时，优先核对出版社、教育主管部门或官方数字教材平台；
- 若只用于查目录、版本和知识结构，可以把它作为检索线索。

这类资源的长期价值在于“找到资料”，不在于把整套教材镜像进个人知识库。
