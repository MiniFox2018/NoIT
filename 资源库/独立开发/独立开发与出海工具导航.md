# 独立开发与出海工具导航

## 定位

这里收录的是两个“工具发现入口”，而不是把其中数百个第三方工具全部复制到 NoIT。

原因很简单：工具状态、价格、免费额度和产品定位变化快，复制一份静态清单很快就会过时。

NoIT 保存：

- 两个目录分别擅长什么；
- 工具选择框架；
- 独立产品从灵感到上线需要哪些工具类别；
- 哪些信息必须回官方重新核验。

## 工具选择的六个判断维度

### 1. 当前必须解决的问题

不要因为工具流行而引入。

### 2. 总拥有成本

不只看月费，还看：

- 接入；
- 学习；
- 维护；
- 迁移；
- 数据导出；
- 人工时间。

### 3. 锁定程度

确认：

- 数据能否导出；
- API 是否开放；
- 是否支持标准协议；
- 停服后如何迁移。

### 4. 使用量增长后的价格

很多 SaaS 在小规模时很便宜，规模上升后成本结构完全不同。

### 5. 合规和数据

特别关注：

- 隐私；
- 数据存储地区；
- 子处理商；
- 安全认证；
- 支付和税务责任。

### 6. 当前状态

采用之前必须去官方重新检查：

- 是否仍运营；
- 当前价格；
- 免费额度；
- 当前 API；
- License；
- 商业使用条款。

## 为什么没有复制源清单里的价格

Awesome Indie Hacker Tools 中部分条目的价格和状态具有明显时效性，个别历史产品也已发生重大变化。

因此，本仓库不把第三方导航中的价格描述当作事实基准。

目录只负责“发现候选”，最终决策以每个工具官方当前信息为准。
