# 微信小程序官方开发与商业化入口

## 定位

这是微信小程序从开发、云后端、支付到备案的官方资源入口集合。

它不保存容易过时的价格、活动额度或具体按钮位置，而用于回答：

> 当前要做某一步时，应该去哪里查最新官方规则。

---

## 1. 微信小程序开发文档

官方入口：

https://developers.weixin.qq.com/miniprogram/dev/framework/

适合查询：

- 小程序框架；
- API；
- 组件；
- 登录；
- 授权；
- 网络请求；
- 基础库；
- 开发规范；
- 开放能力。

正式实现前，应优先用官方文档核对当前接口。

---

## 2. 微信开发者工具

官方入口：

https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

主要用途：

- 项目创建；
- 模拟器；
- 调试；
- 真机调试；
- 代码上传；
- 性能与网络排查；
- 提交前检查。

AI Coding 编辑器可以负责大部分代码生成，但微信生态的真实运行验证仍需要开发者工具和真机环境。

---

## 3. CloudBase / 微信云开发

腾讯云入口：

https://cloud.tencent.com/solution/la

CloudBase 文档：

https://cloud.tencent.com/document/product/876

主要能力：

- 云函数；
- 云数据库；
- 云存储；
- 小程序身份能力；
- AI 模型；
- Agent；
- 小程序生态集成。

适合：

- 独立开发者；
- MVP；
- 希望减少服务器运维；
- 需要快速接入微信原生能力。

使用前重新核验：

- 套餐；
- 资源点；
- 免费额度；
- AI 模型；
- 活动资格。

---

## 4. 微信支付商户文档中心

小程序支付开发指引：

https://pay.wechatpay.cn/doc/v3/merchant/4012791911

JSAPI / 小程序下单：

https://pay.wechatpay.cn/doc/v3/merchant/4012791897

支付成功回调：

https://pay.wechatpay.cn/doc/v3/merchant/4012791861

这些是支付开发的主要事实入口。

接入时重点核对：

- AppID 与商户号；
- API 权限；
- 下单参数；
- prepay_id；
- requestPayment；
- 查单；
- 回调通知；
- 验签 / 解密；
- 重复回调；
- 对账；
- 退款；
- 当前密钥 / 证书体系。

支付相关实现不要依赖第三方教程中的旧参数名称或旧页面位置。

## 5. 工信部移动互联网应用备案

工信部备案通知：

https://www.miit.gov.cn/zwgk/zcwj/wjfb/tz/art/2023/art_920db564162e4312916a01bed6540ad8.html

备案登记表：

https://xzca.miit.gov.cn/bsfw/bszn/art/2024/art_5d3cc7f452c04fdd97b6881a20b656f9.html

备案查询：

https://beian.miit.gov.cn/

- 确认小程序备案义务；
- 查看备案所需信息；
- 查询备案结果；
- 核对当前备案制度。

---

## 6. 微信公众平台

入口：

https://mp.weixin.qq.com/

主要承担：

- 小程序账号；
- 主体；
- 类目；
- 开发设置；
- 认证；
- 版本；
- 审核；
- 备案入口；
- 部分运营和成长计划。

平台 UI 和入口位置变化较快，仓库不长期保存按钮级操作说明。

---

## 7. AI 小程序成长计划

活动通常从微信公众平台或 CloudBase 当前活动入口进入。

当前可参考：

https://cloud.tencent.com/solution/la

CloudBase 2026-07 活动更新：

https://tcb.cloud.tencent.com/blog/2026/07/07/wx-ai-miniapp-plan

注意：

不同腾讯官方页面在 2026 年对 Token、生图额度等描述存在版本不同步。

因此：

- 不把固定额度写进长期成本模型；
- 参与前重新查看当前活动页；
- 记录领取日期和有效期；
- 按补贴结束后的成本验证商业模型。
