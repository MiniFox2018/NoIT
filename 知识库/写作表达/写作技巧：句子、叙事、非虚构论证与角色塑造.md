# 写作技巧：句子、叙事、非虚构论证与角色塑造

## 如何使用这组写作建议

这份资料是多位作家经验的汇集，而非统一科学理论。判断编辑是否有效，首先看**是否便于读者准确理解**，其次看节奏、情绪和表达趣味。与 [[写作练习与真实表达：从初始意念到重读重写]] 分工：后者聚焦产生真实材料，这篇聚焦形成可读的文章与故事。

## 通用写作

- **明确受众与沟通情境**：读者知道什么、为何读、需补什么信息？短信、论文、故事的说话方式不同。
- **先允许坏草稿存在**：创意水龙头是写作练习隐喻，不必在第一句话自我审查；没有保证写满多少字就会出现好点子。
- **长短句变化**：连续同样长短的句子容易单调。朗读可以发现节奏问题；长句承担推进，短句负责停顿。
- **句子焦点**：主动句通常让执行动作的人更醒目，被动句可把注意力放在承受者身上；不机械禁止被动语态。
- **准确词汇**：删除无意义的修饰，使用可见的动作、具体物件和感官细节，减少「很难过」「非常美」一类空泛判断。
- **重复与歧义**：有意的平行结构可以强化观点，无意识的句首重复和含混代词会干扰理解。

## 非虚构：让人沿着论证往前走

1. 以真实情境、反直觉问题或明确争议开头，不堆大话。
2. 为每一段写一句**迷你论点**；把这些句子排列，检验是否能构成全文主张。
3. 用例子或生活情境把抽象概念落地，首次使用术语时解释。
4. 先解释读者需要的背景，再陈述新的结论；按功能分组事实、反例、比较和推论。
5. 使用小标题、适当的小结与节奏变化，让读者知道当前走到论证的哪一层。
6. 对有力的反方意见给予公平回应，不靠漂亮修辞代替证据。
7. 制造悬念必须兑现，不要为抓眼球歪曲事实。严肃或高风险文体优先准确克制。

## 小说：动机、冲突、变化

- **角色的弱点与需求**应能在具体行动中被看见，不必先写一页人格说明。
- 角色「想要的」与「真正需要的」可能不同；讨喜程度、能力、主动性是三个可观察维度，不需要同时增长。
- 多重冲突动机会让人物更真实：既渴望被理解又害怕暴露，既想自由又需要安全。
- **第三层情绪**：除表面愤怒和悲伤之外，还存在怎样复杂的感受？让具体动作和环境细节表达，而非反复宣告心理状态。
- **对立之网**：主角不仅与单一反派较量，也受到盟友、亲友、制度与自己的价值观挑战；盟友批评有时比打斗更能推动道德转变。
- 场景应改变角色关系、信息、风险、地位或计划；过场不要只写「之后过了一天」。
- 世界规则必须影响真实选择；反转应尽量回收铺垫并兑现故事所许下的期待，不能依赖纯随机。

## 可执行编辑流程

| 顺序 | 核对任务 |
| --- | --- |
| 1 | 中心观点、事实与论证是否成立 |
| 2 | 段落迷你论点是否有清楚的先后关系 |
| 3 | 读者未知术语与背景是否得到解释 |
| 4 | 主语焦点、动词、歧义、句长和段落节奏 |
| 5 | 小说人物的动机、弱点、冲突与后果 |
| 6 | 朗读检查、实质删改、检查未回答的反方 |

可复用指令：先抽取中心主张和逐段迷你论点，标注事实来源与潜在反例；再调整句长、主语焦点、具体动作和重复问题。若是小说，另审人物动机、价值冲突、场景变化与悬念兑现。不要为追求写作套路而改变原作者要表达的事实和立场。
