## 二、专题范围与词汇边界

- **机器人（Robotics）**：由传感器、执行器、机电系统及软件组成，能在物理世界感知、规划或执行动作；包括移动机器人、机械臂、人形与双足/四足平台、工业与服务机器人。
- **具身智能（Embodied AI）**：强调智能体在物理或模拟环境中通过观察、行动和反馈完成任务；机器人学习、模仿学习、强化学习、视觉-语言-动作模型（VLA）、仿真到现实迁移是常见研究路径，但具身智能并不等于必须采用人形机器人。
- **机器人操作（Manipulation）**：夹爪/机械手、机械臂、标定、运动学、路径规划、示教、抓取与装配。
- **自主移动（Autonomy）**：里程计、定位与建图（SLAM）、导航、避障、状态估计与可靠运行。
- **机器人工程栈**：电气安全与电源 → 微控制器/驱动/执行器 → 传感和闭环控制 → 机械结构 → ROS 2 与系统集成 → 感知和规划 → 数据采集与学习策略 → 实机验收。
- **不混淆的同名项**：聊天机器人、Telegram bot、网页 Agent 不自动属于物理机器人专题；3D 动画的 humanoid 角色绑定不等同机器人运动控制；作者 Isaac Asimov 不是 NVIDIA Isaac Sim。相关内容继续放在原用途分类。

## 三、学习与实践的推荐顺序

1. **基础硬件可观测**：会读电路图，使用万用表、逻辑调试和串口日志，理解电源、驱动、电流、PWM、中断与传感器接入；先在安全条件下验证最小电路。
2. **闭环控制**：用编码器、IMU、滤波和 PID 让轮速、位置或姿态可测、可调；记录目标值、实际值、扰动和失效模式，而不只保存演示视频。
3. **机械和制造**：CAD、参数化结构、传动和公差；打印结构件、装配、标定、改进。机械臂可作为贯通机械、固件、遥操作与数据采集的平台。
4. **ROS 2 与仿真**：节点、Topic/Service/Action、TF、URDF、ros2_control、Gazebo 等组成可分模块调试的系统；再延伸到 SLAM/Nav2 或 MoveIt 2。安装前按操作系统核查发行版和版本兼容。
5. **机器人学习**：以数据采集、任务定义、行为克隆或其他模仿学习基线为起点，再判断何时需要 VLA、强化学习与 sim-to-real；离线指标不等于实机成功率。
6. **端到端验收**：记录可复现环境、硬件 BOM、风险与急停、电源保护、失败回放、成功率/误差、运行时长和恢复方法，形成可以答辩的作品集。

具体步骤、月份安排、项目验收标准和错误处理，以[完整六个月路线](./机器人工程师六个月实践路线：从电子到机器人学习.md)为准；本页不替代正文。

## 四、工程问题的最小排查框架

| 出现的问题 | 先检查哪一层 | 可验证证据 |
| --- | --- | --- |
| 设备复位或执行器抽动 | 供电、电流余量、接线、控制时序 | 电压记录、供电波形、错误日志 |
| 运动超调、抖动或漂移 | 传感器校准、采样频率、滤波、闭环参数 | 阶跃响应、时间戳、重复实验 |
| 仿真成功、实机失败 | 摩擦/间隙、驱动限制、延迟、感知域偏移 | 对比实验与失败样例 |
| 自主导航不稳定 | 坐标变换、里程计、地图质量、环境变化 | TF 树、轨迹与 rosbag |
| 学习策略成功率不稳定 | 数据覆盖、任务定义、训练与评估隔离、场景随机性 | 分场景成功率、置信区间与失败归因 |

以上是检索和诊断顺序，不代表每种故障仅有单一原因；涉及真实运动设备时必须有人员隔离和适当安全措施。
