# 旅行照片修复与AI二次创作：真实感、提示词与创意玩法

## 使用这份手册

本手册把四份 2026 年 10 月旅行照片资料整理为一条可实践的主线：**先保留原件 → 再修复真实照片 → 核验人与环境 → 最后另做创意版本**。不是所有“不好看”的照片都应该交给生成模型重绘；重要的是先判断究竟要**记录当时发生的事**，还是要**用当时的照片创造新作品**。

- **纪实修复**：曝光、白平衡、旋转、轻微降噪、清除画面干扰。原则是只动必要区域，不捏造原场景或面貌。
- **参考图合成**：同次连拍补救闭眼、多张照片制作跨时空合影。必须指定每张图的职能；合成不是现场原片。
- **创意叠加**：原片保持为底图，添加手绘、票据、海报版式或少量 UI。
- **世界重构**：人物变为漫画角色，场景成为游戏、微缩世界、纸艺物件或超现实空间。明确标注“AI 创意版”。

本专题强调**图像的可复现做法和失败边界**，与通用的 [[AI图像生成与编辑Prompt：场景描述、文字、参考与可控迭代]] 相互补充，不重复一般性的构图和多参考图原则。

## 一、六步工作流

1. **保存原图**：优先使用原始尺寸和未反复转发的照片。原片永不被生成结果覆盖；记录原片与创意成片之间的关系。
2. **先分类**：人像、多人合影、建筑风景、夜景、餐饮、纪念创作；明确是“局部纠正”还是“有意幻想”。
3. **写清编辑范围**：指定哪张为不可重绘底图、哪一处允许修改、哪些人和对象必须保留。如果工具支持选区，先用遮罩圈定区域。
4. **一次解决一个问题**：先去干扰物，再分别做曝光、色彩和裁切；一次加入多个重建指令会使失真来源难以追踪。
5. **对照验收**：以原片为基准逐人检查五官、发型、衣服、肢体；逐处检查建筑直线、重复纹理、文字招牌、食物数量和阴影。
6. **分支创作**：从原片或最近一次确认的修复版起步，独立生成海报、贴纸、游戏图、纪念品效果图。不要对一张已错误重绘的人脸继续叠加修改。

### 三套可直接改写的基础提示词

**A. 自然修复：**

~~~text
以我上传的照片 A 为唯一摄影底图。只修改【具体位置】的【一个具体问题】，
修改程度为【轻微/适度】，保持原图画幅和主要构图。
必须保留【人物及同行者身份、发型与服装、表情、现场天气、光源方向、
原有物品数量、建筑和文字】。被遮挡、看不清的真实信息不要臆造；
有无法可靠恢复的细节可以保留原状。只输出一张编辑结果，不加标题或对比图。
~~~

**B. 两图局部参考：**

~~~text
照片 A 是唯一底图；照片 B 仅用于参考【同一人物的睁眼状态/同一地点的空镜】。
在 A 的【小范围】修复【问题】，B 不提供其它人物、服装、环境或全局风格。
A 中其余人脸、身体、景物和相机视角保持不变。最终逐项核查局部接缝。
~~~

**C. 从实拍到创意版：**

~~~text
照片 A 提供【人物身份/真实景物】，照片 B 若存在仅提供【排版或另一空间】。
创作【最终载体：旅行海报/游戏界面/纪念品/超现实摄影】，画幅【比例】。
主视觉是【主体与动作】，次视觉是【仅一项有故事的变化】；
空间关系、受力、接触阴影与色调统一。必须保留【身份与可辨认细节】，
可重构【明确允许的对象】；画面文字只有“【逐字文案】”。
这是一张 AI 创意作品，不是未经编辑的纪实照片。
~~~

**返修话术：**“上一版的【位置】出现【可观察错误】。请从原始照片 A 重新开始，只修【小区域】；保留【具体身份、物件、构图、文字】，不要继续其它美化。若不能可靠恢复，保留原样并指出限制。”生成工具口头承诺“保持原图不变”，**不能替代人工逐项比对**。

## 二、14 类真实照片修复：目标、提示词与验收

这 14 类对应系列资料的第 01—14 场景。每类单独保留失败条件与补充情境，不能只用“美化一下”取代。

| 场景 | 可以直接用于提示词的操作 | 必须锁定和复核 |
| --- | --- | --- |
| **01 景点路人抢镜** | 只删除指定游客及对应阴影，按邻近纹理补齐地面、墙体、栏杆；同行者逐个点名保护。古门洞优先移除少数近景干扰者。 | 门框、砖缝、台阶、栏杆不断裂；被人完全挡住的景物并无可靠原貌，必要时用空镜参考。 |
| **02 逆光黑脸** | 只调整人物面部与衣物暗部，天空、高光、水面或雪山保持原有亮度。 | 自然肤质、眼鼻结构；不要把雪山提成无纹理白纸。普通局部曝光优先于生成五官。 |
| **03 阴天灰片** | 保留雨、云与远景朦胧，改善曝光、白平衡与近景层次；湖面倒影和芦苇不重绘。 | 灰天不是缺陷；蓝天、太阳或新云属于另做的天气幻想版本。 |
| **04 夜市噪点** | 只缓解暗部彩噪与严重偏色，保留夜色、灯笼、招牌、衣物与蒸汽。 | 不把夜景变白天；招牌错字、衣服糊成涂抹块都算失败。 |
| **05 歪斜建筑与海平线** | 先用旋转、透视校正和裁切；海平线优先水平，建筑优先保主要竖直线。 | 人不被拉宽、拉长；门窗数量及灯塔结构不变。为求完全垂直而变形不值得。 |
| **06 横图补成竖图** | 原片放中心，向天空、墙面、草地等简单边缘扩到 3:4；露营图保护帐篷、椅子和人员。 | 不复制帐篷、不创造新地标、不凭空补人体；扩图接缝难控制可改为纯色留白。 |
| **07 轻度模糊或运动抖动** | 仅清理压缩痕迹、强化仍可辨认的轮廓；骑行照保留运动拖影。 | 已丢失的眼、字、招牌细节无法可靠“找回”；越修越像陌生人就停止。 |
| **08 自拍疲惫与临时瑕疵** | 局部改善脸部受光、黑眼圈及临时痘痘，保持毛孔、细纹与年龄。车窗自拍保留窗上倒影。 | 痣、眼型、牙齿和下巴仍能对上本人；不要默认瘦脸、磨皮、隆鼻和改变年龄。 |
| **09 风吹散发遮眼** | 只整理挡住眼或嘴角的几根发丝，其他乱发保留，仍看得出现场有风。 | 不重做发际线或发量；若大面积遮住五官，换片通常优于凭空补脸。 |
| **10 多人合照有人闭眼** | A 为最满意合照，B 为同次连拍的同一人睁眼参考，仅修改 A 中相应眼区。 | 不能拿别人眼睛、别的年代的自拍或一张新脸代替；所有同行者逐个验收。 |
| **11 合影明暗不均** | 对左暗、右亮等不同脸分别做局部曝光与白平衡调整，而非所有人统一美白。 | 保留自然肤色、年龄和不同人物身份；树荫光斑与现场受光方向不变。 |
| **12 餐厅暖光偏黄** | 用原照片白瓷盘/中性色作白平衡参照，恢复牛肉面、青柠、鱼皮等真实颜色。 | 菜仍是原菜：配料、熟度、份量、焦痕不变；不能为了“好吃”添加油光与蒸汽。 |
| **13 桌面杂物** | 只移除空白桌边的纸巾、塑料袋或包装，保留餐具、菜品、手写便条和生活感。 | 遮挡菜品的物体不能靠 AI 猜回被遮住的真实食材。 |
| **14 咖啡甜品拍摄不出彩** | 改善主体与背景对比、局部曝光、白平衡；保留拿铁奶泡、蛋糕切面、可颂焦色。 | 杯沿几何、拉花形状、奶油高度和实际分量都不能变化。 |

### 面向实际操作的四个专项示例

**景点去路人（保全同行者）**

~~~text
编辑照片 A：保留中间的人、左侧戴帽同行者、衣物、姿势和景区建筑；
只消除右后方两名陌生游客及其阴影。缺口只依据当前可见墙面、地砖
和栏杆纹理进行保守衔接。若门洞砖缝不能可靠延续，不要自行改变建筑结构。
不要重绘人物面孔，不改变光照。仅输出单张修复图。
~~~

**雪山逆光（亮脸不漂白雪）**

~~~text
把 A 中两名人物脸上的阴影适度提亮，保留面部真实肤色、五官比例与毛孔。
雪山高光、雪面细纹、天空明度维持原样；不增加补光灯的投影，
不磨皮、不换天气、不改变衣服。以人脸可辨识且雪纹理仍在为完成标准。
~~~

**同一次连拍补睁眼**

~~~text
A 是最终合影；B 是同一次连拍中右侧穿深色外套者睁眼的一帧。
只参考 B 的此人眼睛形态、睁开幅度、视线与眼睑，将其匹配到 A 的头部透视。
其他面部区域、同行者、餐具及背景都按 A 保留。不要整个换脸或额外加妆。
~~~

**餐厅色偏与菜品完整性**

~~~text
只调整照片的黄光色偏和轻微欠曝，以画面中白盘的中性色为参考。
保留实际食材种类、数量、烤痕、油脂、器皿与摆盘。不要自动添加
奶泡图案、肉片、蒸汽或反光，不把食物变成广告渲染图。
~~~

## 三、从问题片得到新作品：01—14 对应的创意变体

以下变体**各自独立使用**，不要把一行里的三个效果叠在一张图上。每次沿用前面的创意底板，填入具体的“创意载体/变化点”，且明确是非纪实版本。这里保留了原三篇中每一类场景附带的三个独立“还可以这样玩”方向。

| 原场景 | 创意 A | 创意 B | 创意 C |
| --- | --- | --- | --- |
| 01 景点游客 | **掌心景点**：把原地标缩成托在手上的小模型，接触阴影可信 | **同一人三次游览**：同一穿搭，分别走路、拍照、看地图，视为分身创作 | **限定营业牌**：在空白角落加只含一条短句的小告示，不挡主角 |
| 02 逆光 | **旅行影子**：只把人物地面影子改成背行囊的轮廓，不加第二人 | **瓶中的夕光**：剪影和原景放进玻璃容器，不臆造被黑暗遮住的脸 | **光影三幕**：一套人物动作在早、午、晚三种灯光下并列，注明光线幻想 |
| 03 阴天 | **五色采样卡**：从云、水、树和建筑实际颜色取色，不乱编色号 | **云中纸城**：沿原云边缘露出由已有建筑概括的纸艺小城 | **雨天掌机关卡**：建筑道路概括为像素级别，保留雨和少量游戏 UI |
| 04 夜景 | **一罐夜色**：把灯光街景缩进透明罐，保留原建筑轮廓 | **霓虹小动物**：仅在空白夜空用灯色光轨勾出一只动物 | **城市电路板**：道路化作线路、楼宇化作节点的艺术模型 |
| 05 歪斜 | **城市立体书**：建筑与人物成为纸页弹出层，保持主要形状 | **溢出相框的海浪**：仅少量海水越过边框，空间接触真实 | **桌上的木积木**：现有地标转成木块，门窗和屋顶仍可辨认 |
| 06 扩图 | **穿出手机框**：原人只让已有的一只手与栏杆微微跨越屏幕 | **旅行长卷**：用用户真实上传的其它沿途照片延展左右，按实际顺序 | **六面回忆方盒**：六张照片分占六个纸面，属于概念效果图非生产展开图 |
| 07 模糊 | **针脚旅行**：用可见姿势与轮廓生成刺绣，不虚构脸 | **像素回忆**：服装和地标概括为掌机色块，故意保留低分辨率感 | **焦点丢失的气氛照**：强化模糊和情绪而不谎称高清复原 |
| 08 自拍 | **个人杂志封面**：标题和三条副标题来自真实当日记录 | **羊毛毡自己**：保留痣、眼镜和发色等识别特征，显露羊毛纤维 | **表情三连**：用三张真实自拍拼接，不生成不存在的表情 |
| 09 散发 | **风线手绘**：沿原发丝方向加入少量淡色气流曲线 | **发丝星座**：少数外围头发化为小光点与星座连线 | **花草发梢**：限定仅引入原照片中已有的植物，不盖住面部 |
| 10 闭眼 | **做梦气泡**：原本闭眼不修，在人物头顶画所想食物或床 | **六格底片**：六张真实连拍成为接触印样，禁止凭空补帧 | **日月剧场**：睁眼/闭眼者头顶分别只加极小太阳/月牙 |
| 11 明暗 | **旅行通行证**：每人一张昵称角色卡，禁止生成真实身份证/二维码 | **三人天气**：不同人头顶的符号表示各自心情而非实际天气 | **影院纪念票**：片名、昵称与座位代号均由用户提供 |
| 12 黄光美食 | **美食博物馆**：真实菜品成为唯一展件，极小观众做点缀 | **胃口色卡**：从可见配料提五色，不造营养数值 | **面条立交**：把实际面条与葱花转成微缩道路与绿地 |
| 13 桌边杂物 | **餐具吐槽**：最多三个对象的小对话气泡，台词由用户提供 | **悬浮食材清单**：原有碗、餐具、配料分层，不能多出食材 | **饭局档案板**：用户已有菜单、照片、原话与细线索引 |
| 14 咖啡甜点 | **杯中微银河**：一只咖啡杯中出现奶泡星云 | **蛋糕地质剖面**：原层次对应趣味标签，不编配料 | **拿铁小房间**：奶泡变床、杯沿变窗台，人物仅微型虚构 |

## 四、10 类可深度使用的纪念与故事创意（15—24）

创意不只是一种滤镜。每件作品只选**一个主要视觉机制**：时间错位、尺寸错位、容器出框、空间变形、票据信息层、人物动作关系、故事流程或幕后反差。复杂设计首先约束**主角、道具、光线、文字、留白和真假边界**。

### 15. 旅行冰箱贴与纸艺纪念品

- **输入**：有辨认度的人物/地标原片，真实日期、地名（若需要）。
- **做法**：把人物、景点和旅行元素放到一枚有薄金属边、平面印刷面的小冰箱贴中，置于真实家居场景；它是制作概念展示，**不是已打样成品**。
- **变体**：照片自动售货机（窗内真实照片、手从出片口取一张）；行李箱上的 3—5 枚旅行贴标（只用真实去过的站点）；纸艺立体票根（照片主体从纸层立起，文字仅城市/日期/原话）。
- **检查**：纪念品金属边、照片比例、印刷区域完整；若送厂生产，还需独立刀模、材质、颜色、尺寸及工艺文件。

### 16. 淡彩旅行小画

- **输入**：人与宠物、伴侣或食物的有感情动作，不追求每个背景元素都画出来。
- **做法**：中心小幅水彩画，暖白大留白，以少量透明色和干笔表达主体互动，人物身份、衣服、宠物毛色清楚；背景只留两三处环境暗示。
- **变体**：宠物低机位视角；当天五件真实随身物小画；暖白布料上的微型针脚刺绣。
- **检查**：背景不抢主体；生成的水彩是艺术重绘而不是照片真实修复。

### 17. 个人电影海报：公路、悬疑、轻喜剧

- **输入**：清楚的人物与现场环境、真实朋友原话；先选一个类型而不是混合。
- **做法**：公路片用道路纵深、远处小人物与大面积天空；悬疑片用近侧脸、雨夜、局部双重曝光；轻喜剧用朋友间有明确因果的动作（三个人找路、系鞋带、拿咖啡）。片名成为主视觉一部分，必要时重新构图。
- **变体**：朋友全部出演；“休息时间失踪”幽默悬疑；同行者、宠物、食物的片尾字幕名单。
- **检查**：缩小后先看见人物与标题；不要伪造真实上映、明星、获奖或既有影视品牌。

### 18. 食物中的微缩旅行者

- **输入**：45°角可看清主体食物形态的碗、火锅或蛋糕照片。
- **做法**：真实食物占主角，缩小到成人比例的虚构人物只作小型叙事点，接触阴影与景深一致；面条可作道路、蛋糕奶油可作滑雪坡、鸳鸯锅清汤一侧可作温泉平台。参考案例给出的尺度控制为**旅行者合计画面面积约 6%—8% 以下**，是构图指导，不是跨模型硬约束。
- **变体**：锅沿温泉、奶油滑雪、面条通勤城。
- **检查**：食物本体仍清晰可辨；不能当成餐馆出品、分量或卫生条件的实拍证据。

### 19. 一日食欲地图与双人美食路线

- **输入**：3—4 张真实菜品、2—3 张街景、地标照片；真实行程、时间、店名和花费。
- **做法**：把街景摄影作为主画面，少量食物摄影裁片沿一条红色路线排列，严格按照用户提供顺序标记，标题和真实趣事点到为止；两人可以用两条不同颜色路线在晚餐合照会合。
- **变体**：桌上餐巾纸手画路线；一张收据向远处长成街道；双线各自觅食最终交汇。
- **检查**：如果为视觉重新排列过地理位置，标明“艺术路线示意”；**未实际核验的距离、地址、耗时不可编造，也不可视为导航地图**。

### 20. 同行者的“电量”与团队性格

- **输入**：同一趟旅行的朋友合照及本人确认的口头禅、出游分工。
- **做法**：三人在同一长椅上，以真实姿态表达疲惫、咖啡续命和跃跃欲试；电池图标只是轻度可视化旁白（例如 1%、35%、100%），不代替脸部表情。
- **变体**：每个人头顶不同心愿的轻双重曝光；三个人按实际分工形成电影式连续长卷；朋友背包里弹出实际带过的五件物品。
- **检查**：每位朋友只出现一次，人数和身份保持，玩笑不冒充真实状态数据。

### 21. 家人的跨时间合影

- **输入**：年轻时期照片 A、现在照片 B，最好双方脸部和衣着可辨。
- **做法**：让“年轻”和“现在”两版人物处在统一光线下，但**不擅自把现在的长辈年轻化**。年龄差本身就是主题；跨时代同框一定标为幻想合成。
- **变体**：举旧照片衔接今天的街景（对应不上之处不伪装吻合）；今天的父母散步，但影子牵着小时候的孩子；宠物视角的三条“气味旅行线路”。
- **检查**：四人来自两对时空影像的身份逻辑正确；骨相、皱纹、发色、服装不串图。

### 22. 把一片海装进行李箱

- **输入**：风景照 A 与返程家中敞开行李箱 B。
- **做法**：现实空间完全沿用 B；只让 A 的海景出现在箱子里，少量海水越过箱沿；玄关、墙面、鞋与旅行箱的硬材质结构仍真实，泡沫与反光沿相同照明方向。
- **变体**：沿途风景化作衣摆/围巾末端；人回家了、影子还在度假；撕开返程车票后露出旅途城市。
- **检查**：一图只突出一处“不可能”；不把整个房间变成另一场景，不破坏箱壁、拉链与接触阴影。

### 23. 把当天照片连成情绪线

- **输入**：多张当天真实照片，并给出真实先后顺序与同伴视角。
- **做法**：把出发、疲惫、抵达、夜晚等片段排成一条可读的故事线；情绪通过实拍、大小变化、摄影裁切和少量路线标注表达，不硬编新经历。
- **变体**：一天住进分层建筑；同一天两个朋友的并行版本；九张照片沿图中方向、动作或色彩形成视觉接力。
- **检查**：时间轴信息来自上传材料，不能把图像模型猜测的时间作为事实。

### 24. 出片与幕后片场、废片摄影展

- **输入**：一张“成片”与实际拍摄过程/失误图，如果没有幕后素材，则应写明是“幻想片场”。
- **做法**：把朋友圈大片与摄影机、灯架、导演走位、摄影助理等放在同一叙事中，制造主视觉和幕后狼狈的反差；废片本身还可被挂在精心打光的美术馆墙面。
- **变体**：为废片举办一本正经的摄影展；照片中的人物从画面里走出修改机位；网红打卡照呈现大型摄影棚布景背面。
- **检查**：真实拍摄记录与 AI 添加的设备、工作人员要标明，不制造虚假的幕后证据。

## 五、另一来源：旅行照片的 21 个详述设计样式

来源《国庆相册里舍不得删的废片，我找到了 25 种新玩法来拯救它们！》在上传正文里有 **21 段以引用格式给出的独立长 Prompt**，另有肤色调节、去游客、灰天层次、换蓝天的叙述性案例。下面依原文叙事顺序逐项保留可复用的画面机制；这些机制与上面相近者合并理解，但**变体约束仍保留**。

### 人像、合照：11 种

1. **对称双区独立杂志封面**：上下等高、中央两个同尺寸正方形窗（原示例约占画布宽 44%—48%）；上方用主体代表色背景与黑白丝印网点，下方为摄影主体加主色线描窗。网格轴线精确一致。
2. **漫画登机牌**：一张图保人物身份、一张锁票面摄影与排版；竖版 9:16；角色全身位于票面安全区，互动仅以倚靠、抓边或小幅破框之一实现；不遮票号、标题与条码。若原照只有半身，补出的下半身明确是 AI 推断。
3. **美式复古模切海报**：实拍主角完整抠出并加粗白色外框；强撞色背景、巨型奶油白标题和小型怀旧贴纸；前景仍是摄影而非卡通。
4. **JRPG 旅行任务**：真实旅行背景保留，主角重构为早期掌机游戏 NPC；下方对白框，空白区域加少量任务、道具或经验值 UI；文字讲当时经历而不盖主角。
5. **立体城市地图人形定位**：人物重构为巨大站在俯视地图定位圈上的形象，配有限地图控件。生成地名或距离不等于真实可导航数据，**用户提供的地名优先**。
6. **实拍背景＋手绘主角和幻想朋友**：原地标、建筑光线完全按实拍；人物改成简洁不规则线描，附近 3—5 个小幻想角色按真实地面和栏杆接触，不出现漂浮；只留一句中文对白。
7. **真人照片＋鼠标乱画对照**：画面上方保持原摄影，下方用老式画图软件风格的锯齿线条和少量溢出色块笨拙重绘，同主题形成强烈幽默反差。
8. **同一人物九宫格抓拍**：三列三行，明确同一时段、同地点、同穿搭，却分别采用远近景、背影、误触自拍、失焦、遮挡和运动拖影；这是一组新生图，不是原片真实连拍。
9. **相册主题手机主屏幕**：人物按原照片可见区域抠为前景，背景柔和虚化；少量应用图标、聊天气泡和一个悬浮照片窗形成层次；不要把手机系统图伪装为真实设备截图。
10. **上原片＋下方互动涂鸦海报**：3:4 画面上下各半；上区原照，下区以照片真实人物/动物/景物裁片为中心，2—3 个黑线小人作推、拉、倚靠等互动，文字不拥挤。
11. **珐琅风群像冰箱贴**：大合影转为有突出金属边、亮面填色与概括线条的纪念贴设计；它与第 15 类哑光“照片印刷磁贴”是**不同工艺外观**，不应合并成同一种效果。

### 风景与空间：7 种

12. **悬浮涂鸦工具卡**：原日落风景为底，中央圆角画板 UI 内以彩色马克笔重画同一主体；涂鸦在卡里，背景仍是实拍。
13. **“今日记忆商店”热敏小票**：摄影背景上只有一张纸质小票；上部由实景提炼插画，下部排四列表格与情绪“商品”；数量、单价、金额必须乘算正确。这里的“价格”是诗意虚构，不是交易记录。
14. **蜡笔外围注释**：只沿原物件外轮廓叠加秋日粗蜡笔线、5—8 个关联的小元素和 1—3 处局部色块；不把整张照片蜡笔化、不增虚构动物。
15. **白色手写旅行注释**：只在空白区加一句标题、一句短文及少量星星、箭头和弧线；原人物和场景保持真实。
16. **实景越界的线稿明信片**：上下各半，上半原片，下半暖白纸面；从照片已有道路、海浪、线缆、树枝等真实元素跨越分界转为单色线稿，再与小人物互动；跨界位置必须连续。
17. **真实城市照＋氛围剪影下半页**：双区各半，上区实拍城市轮廓，下区用少数色块、单一主体剪影、简洁文字提炼其情绪，而不是再次描摹每一栋楼。
18. **复古旅行日志丝网插画**：以象牙白纸为整页，选室内最有辨识度的少数物件按原空间关系排列；粗糙断墨线、有限平色与边角日志文案，保留“去过这家店”的空间性格。

### 美食：3 种

19. **实拍餐桌＋手托微缩菜单绘本**：背景桌面不重绘；只增加手与小书；书中绘画严格取自餐桌原有物件，数量和相对位置一一对应。
20. **手账邮票边框美食拼贴**：照片主画面保摄影质感，周围用锯齿邮票纸边、真实可辨美食小元素与统一背景装饰排版；不要把食物原片整体转插画。
21. **实拍背景＋中央“画中画”手绘缩图**：原餐桌为底，中心贴一幅独立的不规则圆角插画小纸片；小画中重述完整场景而非简单盖一层描线。

**仅有描述、未附独立长 Prompt 的四个修图补充案例**：室内紫光导致人物肤色失真（局部校正肌肤，保护眼镜/头发/身份）；阴暗店内删除游客（复核后方货架与装饰的真实准确性）；灰天海岸适度改善明暗层次（保留真实天气）；阴天城市另做晴天版（天空重构为创意修改，不能当成当天实拍天气）。这些例子分别归入第 02/03/01 类的操作思想，**不冒充已经提供了逐字提示词**。

## 六、创意出图的底层设计与文字约束

### 选择画面机制，而不是堆热门样式

- **保持原底图＋叠加信息层**：手账、票根、手绘箭头、数据小标签，适合一张原本就好看的照片。
- **保留实拍局部＋背景重排**：模切海报、上实拍下线稿、印刷杂志，适合主体轮廓有辨识度的照片。
- **提取主体后更换载体**：纪念磁贴、羊毛毡、纸艺、刺绣，适合人物、宠物或地标轮廓清楚的照片。
- **尺度/时间/空间错位**：微缩食物、跨年代父母、旅行箱里的海、人在地图上的巨型定位；需要一个明确“不可能”的视觉点，其余保持可信。
- **多照片叙事**：旅行路线、一天情绪线、朋友群像，是来源、顺序和关系的工程，不是单图滤镜。

### 冲突时的约束优先级

1. 真实记录作品：原始身份、人数、场景真实性优先于“好看”；不能可靠修复就缩小任务。
2. 高设计密度作品：人物/关键物完整性 → 版式框架 → 主要文字准确性 → 装饰；多余装饰应删。
3. 多参考图作品：身份图锁脸、底图锁场景、排版参考锁布局；每张图只担任明确职能。
4. 凡有“准确姓名、地址、日期、票号、金额、二维码、路线”，由用户提供或可靠数据源核验，不让模型凭空生成。
5. 涉及人物、家人、宠物、儿童和公开发布时，注意肖像及隐私授权；票根和菜单照片里的真实订单号、联系方式、二维码需先遮盖。
6. 变装、补脸、晴天替换、分身、时空同框、微缩世界、模拟现场属于创意编辑，公开分享时标注“AI 创意版”。

### 制作前快速选路

| 照片现状 | 第一选择 | 备选 |
| --- | --- | --- |
| 人物清楚，背景碍眼 | 选区去游客/杂物 | 保留人群，只裁切 |
| 逆光暗脸，景色明亮 | 局部阴影调节 | 保留剪影做创意 |
| 阴雨、夜景、运动模糊 | 克制曝光和降噪 | 纸艺、像素、胶片或手账 |
| 合照局部闭眼 | 使用同次连拍修眼 | 接触印样、多格底片 |
| 美食颜色奇怪 | 参考白色器皿调白平衡 | 色彩样本、菜单卡、微缩幻想 |
| 风景本身漂亮 | 仅增加一句文字或手绘标注 | 二分版式、明信片 |
| 多图值得回忆 | 按真实时间做路线或故事线 | 纪念画册、照片墙、长卷 |
