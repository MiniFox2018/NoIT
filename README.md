# NoIT

由用户主动投喂资料、由 AI 持续完成核验、去重、融合和知识沉淀的个人非 IT 知识与资源库。

NoIT 不负责替代用户在不同平台上的收藏习惯。用户将值得长期保留的链接、网页、PDF、文档等资料提交后，再由 AI 与仓库现有内容进行比对、核验和融合。

## 使用原则

- 收藏只是来源，仓库保存的是经过吸收后的长期价值。
- 同主题多来源优先融合，不默认“一篇来源对应一篇笔记”。
- 同一批次提交不代表同一主题，资料逐篇独立判断。
- 正式知识应尽量做到脱离原始网页也能独立学习和查阅。
- 文档默认使用 Markdown，并兼顾 GitHub 与 Obsidian。
- 长期处理规则统一见 [PROJECT_RULES.md](./PROJECT_RULES.md)。
- AI 工具入口见 [AGENTS.md](./AGENTS.md)。
